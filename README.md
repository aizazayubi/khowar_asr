# Khowar Automatic Speech Recognition (ASR)

An Automatic Speech Recognition (ASR) system for **Khowar**, a low-resource Indo-Aryan language primarily spoken in the Chitral region of Pakistan.

This project explores the use of **OpenAI Whisper** and fine-tuning techniques to develop speech-to-text capabilities for Khowar. The current model provides a baseline for further improvements and future applications of Khowar speech technology.

---

## 🚀 Project Vision

Khowar has very limited digital language resources and lacks mature speech and language technologies. Typing in Khowar can also be difficult and time-consuming due to limited input tools and resources.

The long-term goal of this project is to build a foundation for a broader **Khowar Language Technology ecosystem**, starting with ASR and expanding into applications such as:

* 🎙️ Automatic Speech Recognition
* 📝 Speech-to-text transcription
* 🚫 Hate speech recognition
* 📱 Social media content moderation
* 🎓 Educational transcription
* ✍️ Speech-assisted Khowar writing
* 🏠 Smart devices and voice-controlled systems
* 🔎 Searchable Khowar audio archives
* 🤖 Future Khowar NLP applications

## 📊 Current Results

The current fine-tuned model achieves approximately:

**~65% ASR accuracy**

This result represents a baseline rather than the final target. The next phase will focus on collecting and incorporating additional Khowar speech data to improve recognition performance.

As more diverse speakers, accents, vocabulary, and speaking conditions are added to the dataset, the model is expected to become more robust.

---

## 🧠 Methodology

The project uses **Whisper**, a transformer-based speech recognition model, which is fine-tuned on Khowar speech data.

### Current Pipeline

1. Collect Khowar speech recordings
2. Prepare and clean the dataset
3. Transcribe and align speech
4. Preprocess audio
5. Fine-tune Whisper
6. Evaluate ASR performance
7. Analyze recognition errors
8. Expand the dataset
9. Retrain and improve the model

### Phase 2 — Khowar Hate Speech Recognition

Once a reliable ASR system is established, the next phase will investigate **Khowar hate speech recognition**.

The proposed pipeline is:

```text
Khowar Speech
      ↓
ASR
      ↓
Khowar Text
      ↓
Hate Speech Classifier
      ↓
Safe / Unwanted Content
```

This could eventually support applications such as social media moderation, where spoken Khowar content can be converted into text and analyzed for unwanted or harmful language.

> The hate-speech component is planned as a future research phase and is not currently part of the baseline ASR model.

## 🔬 Research Significance

Khowar is a **low-resource language**, and developing ASR technology for it presents challenges including limited speech datasets, limited language resources, and limited standardized digital resources.

This project aims to contribute toward reducing that gap by creating practical speech technology for Khowar and establishing a baseline that future researchers can build upon.

The broader objective is not only to create an ASR model, but to establish a foundation for **future Khowar NLP and speech technologies**.
